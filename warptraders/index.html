    How to play

    You fly a freighter around a network of sectors. Every warp costs a turn. Make as many credits as you can before turns run out.

    • Ports sell or buy fuel ore, organics and equipment. A port with lots in stock sells cheap. A port that is running low pays well.
    • Buy where it is cheap, sell where it is dear. Every unit you trade moves the price, so big loads cost more per unit.
    • Tap or click a sector on the map to fly there (known routes only). Ports you have visited show the last prices you saw, which go stale.
    • Stardock (sector 1, the gold one) sells extra holds and fighters.
    • Pirates ambush you at random, more often far from Stardock. Fight (needs fighters), pay a toll, or flee.

    Inspired by the classic BBS space trading games. Original code and text.

    Race friends

    Everyone gets the same galaxy and the same number of turns. Highest credits wins. Connects browser to browser, no server. One person hosts and sends each friend an invite code.

    Scores are reported by each player's own browser, so this is friends-only: nothing stops someone from editing theirs.
